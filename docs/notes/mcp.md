# Tools that reach into the editors

- **Unreal MCP** (Epic's experimental `ModelContextProtocol` plugin with `EditorToolset`, enabled in `Velisect.uproject`). Auto-starts with the editor on **port 8010** (`Config/DefaultEditorPerProjectUserSettings.ini`; `node tools/unreal.mjs open` also passes the port). `.mcp.json` registers it as `unreal-velisect`; it only exists while the editor is open. Meta-tools: `list_toolsets`, `describe_toolset`, `call_tool` (`toolset_name`, `tool_name`, `arguments`). Useful: `EditorToolset.EditorAppToolset` (`StartPIE`, `StopPIE`, `IsPIERunning`, `CaptureEditorImage`, `CaptureAssetImage {assetPath}`, `SetCameraTransform`), `EditorToolset.LogsToolset`, `editor_toolset.toolsets.scene.SceneTools`, `...actor.ActorTools`, `...object.ObjectTools`. Without native tools: `tools/pipeline/uemcp.py` (plain JSON-RPC; `python -I uemcp.py call call_tool '<json>' [out.png]`).
- **Python remote execution** (PythonScriptPlugin, `bRemoteExecution=True`): full `unreal` API in the open editor; `node tools/unreal.mjs py <file>` (via `uepy.py`, which picks the node whose project is Velisect). Use it for imports, materials, levels and BP defaults; MCP for PIE and images. With no editor open, `py` runs the same script in the python commandlet (prints come back through the log; about 12 s).
- **Blender MCP** (inspection and quick experiments only): Blender Lab's official server, installed as the Claude desktop "Blender" extension (tools `mcp__Blender__*`: scene/object summaries, `execute_blender_code`, bundled API and manual docs). It talks to the official `MCP` extension in Blender 5.2 (`bl_ext.user_default.mcp`, auto-starts on localhost:9876, needs Preferences → System → Allow Online Access). Not in `.mcp.json`.
- **Blender pipeline** (everything that makes game assets): `node tools/unreal.mjs blender <file>` runs the script in a fresh `blender --background --factory-startup` (`blx.py`; `BLENDER` env overrides the exe), so it needs no open Blender, add-on or user prefs. Scripts share `tools/pipeline/common_bl.py` (`clear()`, `fbx_import()`, `ctx()`, which is empty when headless). `kit.py` = kit meshes, `textures.py` = kit textures, `export_chars.py` = Mixamo characters and takes.
- **Shots:** `shot` levels the view and saves a 1920x1080 HighResShot of the game (not the editor window); `VS_SHOT_CMDS="cmd1;cmd2"` runs console commands first (e.g. `EnableCheats;Teleport` to stand at the wall ahead). `VsReload` (console, the player's Exec) starts a reload for checking it on screen.
